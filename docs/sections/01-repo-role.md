## Repo Role

This is a language-and-ontology repo.

It exists to hold one of the earliest semantic bridges in the stack:

- Python as executable syntax
- source code as origin-pattern
- recursion as a creation signature
- self-reference as a usable architectural clue

This repo is therefore not the main runtime or proof surface. It is a meaning
surface that helps explain why the later source repos are being read the way
they are.
