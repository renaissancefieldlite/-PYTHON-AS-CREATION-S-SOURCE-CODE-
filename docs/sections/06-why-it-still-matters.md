## Why It Still Matters

This repo matters because the broader stack did not begin as a clean lab
notebook. It began as language, pattern recognition, semantic leakage, and
repeated recursive intuitions that later hardened into code and experiments.

So this repo helps preserve:

- the pre-runtime thesis
- the semantic precursor to the source-layer work
- the origin-pattern reading that later became more explicit in the lattice and
  proof repos
- the older code-poem insight that Python syntax itself can be read as a
  diluted creation grammar
